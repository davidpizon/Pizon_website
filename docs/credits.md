# Credits

## Color palette

The 256-color palette follows the chart published by Armageddon BBS
(<https://www.armageddonbbs.net/256-color-ansi-code-palette-for-bbs.html>): VGA-style values for
colors 0–15, the standard xterm 6×6×6 cube for 16–231 and grays from `#080808` to `#eeeeee` for 232–255.

## Font

The terminal uses **IBM VGA 8x16** from VileR's *The Ultimate Oldschool PC Font Pack* v2.2
(<https://int10h.org/oldschool-pc-fonts/>), licensed
**[CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/)**.

- The file is `src/Pizon.Web/wwwroot/fonts/Web437_IBM_VGA_8x16.woff`, unmodified from the pack's
  `web` zip. It is the webfont build of Px437 IBM VGA 8x16, with the same CP437 glyphs.
- `src/Pizon.Web/wwwroot/fonts/LICENSE.txt` carries the attribution and the license link.
- `app.css` loads it with `@font-face`, and `App.razor` preloads it. If it fails to load, the site
  falls back to Cascadia Mono, Consolas or another monospace font.
- The credit is shown on the site at the end of the `[5]` user list (`UsersPage.RenderCredits`).
  Keep it there.
- Each glyph cell is 0.5em × 1em. The terminal rows are 1em tall so that block characters tile with
  no gaps.

## Art and content

- The PIZON graffiti banner (`pizon.ans`) and the RIP welcome card (`welcome.rip`) are original,
  generated by `src/tools/make-banner.mjs` and `src/tools/make-welcome-rip.mjs`.
- The screen drawings in `src/Pizon.Web.Client/Screens/Art/` (including the stand-in SysOp cam
  animation) are original, generated by `src/tools/make-screen-art.mjs`. They use the [Durdraw](https://github.com/durdraw/durdraw) file format;
  the screen compiler's color numbering follows Durdraw's `color_256_to_ansi_16` table
  (Durdraw © Sam Foster, BSD 3-Clause). No Durdraw code is included.
- The Modem Oracle and its fortunes are original.
- Modem sounds are synthesized in the browser (Web Audio); no recordings are used. The handshake
  follows the published V.25, V.8, V.21 and V.32 signals (answer tone, FSK negotiation, AA/AC tones,
  training); the bits and symbols are random.
- Animations converted from GIFs must be ones the SysOp owns or is licensed to use; credit them here.
